# Gannin site

A first layout for Gannin's landing page, as a single static page: open `index.html` in a
browser. The screenshots in `assets/screens/` come from `scripts/capture-screenshots.sh` (see
`docs/SCREENSHOTS.md`); the review screenshot, logos, results, testimonials and badges are labelled placeholders, and
everything said about the product is something Gannin does.

It was designed on a canvas (https://claude.ai/artifact/P6T7NXL5uQFcme12gdSUZ7) and exported
here as plain HTML, CSS and a few lines of JavaScript, with Geist from Google Fonts.
