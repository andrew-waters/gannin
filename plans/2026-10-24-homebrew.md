# Homebrew

## Context

People who manage Mac apps with Homebrew had to download Gannin by hand. The official
homebrew/cask repo needs a notable app (it counts stars and forks), which Gannin isn't yet, so
the cask lives in our own tap. `gannin` is free as a token in both homebrew/cask and core.

Release builds already meet a cask's needs: Developer ID signed, notarised and stapled, with a
versioned DMG URL and a `.sha256` beside it on every release.

## Decisions

- **Own tap**, andrew-waters/homebrew-tap, so the command is
  `brew install --cask andrew-waters/tap/gannin`. Moving to homebrew/cask later is a
  submission plus a `tap_migrations.json` entry.
- **`auto_updates true`**: Sparkle updates the app, so `brew upgrade` leaves it alone instead of
  fighting it. `livecheck` reads gannin.ai's appcast with the `:sparkle` strategy.
- **Bumped by `release.yml`** over a write deploy key on the tap only
  (`HOMEBREW_TAP_DEPLOY_KEY`), as the last step and `continue-on-error`, so the tap never holds
  a release back. `docs/RELEASING.md` has the manual bump.
