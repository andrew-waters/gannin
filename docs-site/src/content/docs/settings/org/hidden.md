Org settings › Hidden lists the pull requests and issues you have hidden, so you can bring any of them back. Open it with the cog beside the account menu in the sidebar's footer, then pick Hidden in the toolbar. To hide something in the first place, right-click a pull request or issue.

Hiding is your own, on this Mac. It is never shared with the team, whatever the org keeps in a harness. Only items that belong to this org are listed here.

## Hidden items

Each row shows the item's title, then its repo and number with "pull request" or "issue". When nothing is hidden, the pane says so and reminds you how to hide something.

| Option | Default | What it changes | Kept |
| --- | --- | --- | --- |
| Unhide | Not applied | The button on a row. Shows that pull request or issue again everywhere. | This Mac |
