Settings › Remote is where you let an iPhone running Gannin Remote see this Mac's Claude Code sessions and answer them. It is off until you turn it on. For setup and what the phone can do, see [Control sessions from your iPhone](/docs/remote/iphone/). Every option here is kept on this Mac only.

## Remote control

| Option | Default | What it changes | Kept |
| --- | --- | --- | --- |
| Allow iPhones to control sessions | Off | Starts listening on the local network for paired phones, and advertises this Mac to them. Turning it off disconnects every phone. | This Mac |
| Name on the network | This Mac's name | The name phones see and find this Mac by. Changing it restarts listening. | This Mac |

Below them a line says whether Gannin is off, starting, or on and how many phones are connected.

## Paired phones

| Option | Default | What it changes | Kept |
| --- | --- | --- | --- |
| Pair a Phone | None paired | Shows a code and a QR code that pair one phone. The code works once, for two minutes. Needs the switch above on. | This Mac |
| Revoke | Shown per phone | Removes the phone and disconnects it at once. It can't reach your sessions again until paired again. | This Mac |

Each paired phone is listed with when it was last seen.
