Where Gannin asks you to write instructions or a document, Claude can help. Both work as a conversation beside an editable draft. Claude can ask questions first, and nothing is saved until you say so.

## Write with Claude

A Write with Claude button (a sparkles icon in some places) sits beside:

- House rules for Claude, in Settings › Sandbox.
- Each saved prompt in Settings › General › Prompts. It may suggest a name too.
- The drafting guidance in Settings › Harness.

It opens a sheet with the conversation beside the draft, starting from what's in the setting. Look It Over asks Claude to suggest changes. Use This Draft writes it to the setting. Guidance is then a change to commit. Cancel asks first if anything changed, and the conversation is forgotten.

## Draft with Claude

The editors for new harness documents (requirements, findings, skills, prompts, learnings) have Draft with Claude. It follows your org's guidance for that kind, which is set in Settings › Harness. Start Over forgets the conversation. Plans use a [planning session](/docs/agents/planning/) instead.

Drafting uses Claude Code on this Mac, or on your Connect with server if it isn't installed here.
