---
title: Keyboard shortcuts
description: Every keyboard shortcut in Gannin, grouped by where it works, with the menu path where there is one.
---

Gannin is happy to be driven from the keyboard. This page lists every shortcut, whether or not it appears in a menu. The "Where" column gives the menu path, or says "Not in a menu" for the ones you only find by knowing about them (or by reading this page, which is rather the point).

The symbols are the usual Mac ones: ⌘ Command, ⇧ Shift, ⌥ Option, ⌃ Control, ↩ Return.

## Everywhere and in the menus

| Shortcut | What it does | Where |
| --- | --- | --- |
| ⌘N | Starts a new issue in the window you are in | File › New Issue |
| ⌥⌘N | Opens a new main window | File › New Window |
| ⌘T | Opens a new tab, joined to the current window | File › New Tab |
| ⇧⌘R | Renames the current window or tab | File › Rename Tab |
| ⌘K | Opens the command palette | View › Command Palette |
| ⇧⌘J | Jumps to the session that has been waiting on you the longest | Window › Next Session Waiting on You |
| ⌘? | Opens these docs in your browser | Help › Gannin Help |

In the Claude Code window, a focused terminal keeps ⌘K for itself, so the key goes to the terminal rather than opening the palette. Click outside the terminal first if you want the palette there.

## Main window

| Shortcut | What it does | Where |
| --- | --- | --- |
| ⌘R | Refreshes (the Refresh link at the bottom of the sidebar, or Retry after a failed sync). Option-click it, or right-click, for Full Refresh | Not in a menu |
| ⌘[ | Goes back one page | Not in a menu |
| Esc | Closes the top drawer if one is open, otherwise goes back one page | Not in a menu |
| ⌘S | Saves the unsaved board field changes on an issue | Not in a menu |
| ⌘↩ | Creates the issue in the New Issue sheet | Not in a menu |
| Esc | Clears the selected days on the Time off calendar | Not in a menu |
| Esc | Clears the filter box in an organisation's Settings (when it has text in it) | Not in a menu |
| Return and Esc | Confirm or cancel the sheet or dialogue in front of you (Start, Save, Done, Cancel and so on) | Not in a menu |

## Command palette

| Shortcut | What it does | Where |
| --- | --- | --- |
| ↓ and ↑ | Move through the results | Not in a menu |
| ↩ | Opens the highlighted result | Not in a menu |
| ⌘↩ | Opens the result in a new tab, without asking | Not in a menu |
| ⌥↩ | Opens the result in a new window, without asking | Not in a menu |
| Esc | Closes the palette (or leaves a question it has asked) | Not in a menu |

## Drawers and pages

| Shortcut | What it does | Where |
| --- | --- | --- |
| ← and → | Step to the previous or next issue in the view that opened the issue drawer | Not in a menu |
| Esc | Closes the drawer | Not in a menu |
| ⌘O | Opens the issue on GitHub (in Assign to Categories) | Not in a menu |
| ↓ and ↑ | Move through the branches or worktrees in the Repositories popovers, and through the choices in a searchable picker | Not in a menu |
| ↩ | Picks the highlighted branch, worktree or choice | Not in a menu |

A drawer's arrow keys only work when nothing inside it wants them, so typing in a field keeps its own arrows.

## Claude Code window

## Investments

These work in Assign to Categories, which takes you through issues one at a time.

| Shortcut | What it does | Where |
| --- | --- | --- |
| 1 to 9 | Chooses the category with that number | Not in a menu |
| ← | Goes back to the previous issue | Not in a menu |
| → | Skips to the next issue | Not in a menu |
| ↩ | Reviews and writes your choices (or Done, when nothing is written to GitHub) | Not in a menu |
| Esc | Cancels | Not in a menu |
| ⌘O | Opens the issue on GitHub | Not in a menu |
